# 💰 Conta Fácil

Sistema web desenvolvido para facilitar o controle e a organização de contas pessoais.

O projeto permite cadastrar, editar, excluir e marcar contas como pagas, além de apresentar um dashboard com resumo financeiro e relatórios.

## 🚀 Demonstração

🔗 **Acesse o projeto:**  
https://controle-de-contas-sooty.vercel.app/

## 📌 Funcionalidades

- 📊 Dashboard financeiro
- 💰 Visualização do total de contas
- ✅ Controle de contas pagas
- ⏳ Controle de contas pendentes
- 🔴 Identificação de contas atrasadas
- 📅 Visualização das próximas contas
- ➕ Cadastro de novas contas
- ✏️ Edição de contas
- 🗑️ Exclusão de contas
- 💾 Persistência dos dados com LocalStorage
- 📈 Relatórios com gráficos
- 👤 Personalização do nome do usuário
- ⚙️ Página de configurações
- 📱 Layout responsivo para diferentes dispositivos

## 🛠️ Tecnologias utilizadas

- React
- JavaScript
- Vite
- Tailwind CSS
- Recharts
- LocalStorage
- HTML5
- CSS3

## 🎯 Objetivo do projeto

O Conta Fácil foi desenvolvido como projeto de estudo e portfólio com o objetivo de praticar conceitos importantes do desenvolvimento Front-end moderno.

Durante o desenvolvimento foram trabalhados conceitos como:

- Componentização com React
- Hooks (`useState` e `useEffect`)
- Gerenciamento de estado
- Props
- Formulários
- Manipulação de dados
- Persistência de informações no navegador
- Responsividade
- Criação de gráficos
- Organização de componentes e páginas
- Deploy de aplicações React
